## 🌟 About

A single self-contained `index.html` — no build step, no framework, no dependencies beyond a Google Fonts link. It loads fast because there is almost nothing to load.

- 🌍 **Bilingual** — EN/ES toggle that remembers your choice in `localStorage` and defaults to your browser language
- 📱 **Responsive** — fluid type with `clamp()`, auto-fitting grids, zero horizontal overflow down to 375 px
- 🎨 **Themed with CSS custom properties** — the whole palette is six variables

---

## 🚀 Local preview

```bash
python3 -m http.server 8000     # http://localhost:8000
```

## 🇪🇸 En español

Un único `index.html` autocontenido: sin build, sin framework y sin dependencias más allá de un enlace a Google Fonts. Carga rápido porque casi no hay nada que cargar.

Incluye un **selector EN/ES** que recuerda la elección en `localStorage` y arranca en el idioma del navegador, tipografía fluida con `clamp()`, grids que se auto-ajustan y cero desbordamiento horizontal hasta 375 px de ancho. Toda la paleta son seis variables CSS.
